## 2. What shipped this session

### 2a. Kickstarter story export — text was too small (`14110c4`)

**Root cause:** the exporter rendered the *desktop* layout at a 980px viewport (1888px PNGs).
Kickstarter displays story images in a ~680px column, so it downscaled them ~0.72× and 17px body
text arrived at ~12px. The bug was the **render width**, not the font CSS.

**Fix:** render at **560px CSS / 3× device scale** → 1812px PNGs, text ~1.9× bigger. 560px sits
just above the page's own 34rem breakpoint, so the games grid keeps 2 columns and the cast 3 — the
block structure survives. A phone-width (~420px) render would match the Zwaptz reference exactly
but stacks the 14 game tiles one per row.

The exporter also moved **out of a temp scratchpad into the repo** (it would otherwise have been
lost): `kickstarter/export_ks.py`. It now sources from the locally built self-contained preview
rather than the live site, hides the sticky nav before capture, and does the rounded-corner +
shadow presentation itself.

```bash
python kickstarter/build.py && python kickstarter/export_ks.py
# -> kickstarter/dist/story/NN-slug.png  +  kickstarter-copy.txt   (dist/ is gitignored)
```

**Gotcha that cost a round trip:** the owner uploaded the OLD images to Kickstarter and reported
the text still small. Tell them apart by the stat row in block 01 — **new = 2×2**, old = all four
in a single row.

### 2b. AI stage directions leaking into chat (`24fc669`)

Every character prompt already said "no markdown, no stage directions" — `host.js` even says why:
"(this may be read by a voice)". DeepSeek ignored it and emitted `*straightens non-existent bow
tie*`; nothing stripped it, so asterisks rendered literally and would be spoken aloud once 11Labs
lands. A prompt rule the model already disobeys is not a defence, so the guarantee now lives on the
output path: `apps/server/speech.js`, applied to John, both Rex paths, and the banter engine.

**Do not "simplify" this into deleting everything in asterisks.** That was the first attempt and it
destroyed the joke — `I have a *business* degree` became `I have a degree`. Narration is removed,
**emphasis is unwrapped and the words kept**. A span is narration when it runs 3+ words, contains a
comma, or opens with a stage verb. It also repairs stranded punctuation and preserves ellipses.
Lines that were *only* narration return `""`; all four call sites already fall back to canned lines.

## 3. What is built but NOT deployed (`a671223`)

"Ask John" — John as PlayZoo's customer-support agent. Two surfaces, one gag: on the campaign page
**Rex** tells visitors *"ask John — fair warning, he'll try to sell you rubbish, don't buy it, and
he loves being called a trash panda."* Both halves are a stitch-up.

- **`apps/web/src/routes/AskJohnRoute.tsx`** at `/ask-john`. The app uses **hash routing**, so the
  real public URL is `playzoo.snapaweb.com/#/ask-john`. Deliberately public — Kickstarter visitors
  have no backer code yet, and gating it would break the funnel the campaign block creates. Repeats
  Rex's warning at the top (the joke does not land if the visitor arrives cold) and offers
  "you trash panda" as a one-tap opener.
- **`apps/server/john.js`** — `/api/john-chat` gains optional `mode`. `mode:"agent"` appends
  `JOHN_AGENT_RULES`: answer the real PlayZoo question **first** (a support agent who never helps is
  annoying, not funny), then ~1 reply in 3 swerve into selling freshly invented worthless trash,
  priced in shiny acorns, with snappy closer energy. The item is improvised every time, never a
  fixed list — the unpredictability is the joke and a list repeats on regulars. He never takes
  money; it is a bit, not a transaction. The first trash-panda hit makes him **accuse the visitor of
  being put up to it by Rex** and rant about Rex. Without the flag, waitlist John is unchanged.
- **Kickstarter block 11** in `kickstarter/body.html`, placed **after** the pledge block on purpose:
  whoever scrolled past the CTA without backing is the person with an unanswered question. Carries
  the URL as visible text because an exported PNG has no clickable links.
- **Assets:** `GRAPHIC ASSETS/John B.png` → `apps/web/public/crew/john-agent.png` (640px RGBA
  circular cut-out, transparent corners, agent-card portrait). `John on the Desk .jpeg` →
  `apps/web/public/bg/john-desk.jpg` (1600px, page header + block 11 figure). Both ship **with the
  cigarettes as drawn** — the owner was asked and chose that explicitly. Bubble-size avatars stay
  `/avatars/raccoon.png`; the call-centre portrait is far too detailed to read at 26px.
