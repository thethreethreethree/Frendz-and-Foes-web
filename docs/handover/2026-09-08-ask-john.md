## 1. Deploy state — READ THIS FIRST

Push-to-deploy IS live on the Hetzner box: a systemd timer (`frendz-autodeploy.timer`, ~60s)
detects a new commit on `origin/main`, pulls, `npm install`, `npm run build`, and restarts
`frendz-and-foes.service` **only if the build succeeds**. Normal deploy is **commit + push, wait
60–90s, then VERIFY the public URL.** A push is not proof.

### How these were verified — repeat this pattern, do not shortcut it

A `200` is NOT proof: the server falls back to `index.html` for unknown paths, so a missing file
also returns 200. Check content type and size against a negative control.

```bash
curl -s -o /dev/null -w "type=%{content_type} size=%{size_download}\n" \
  https://playzoo.snapaweb.com/crew/rex-warning.png
# -> image/png 491712  (byte-identical to the local file)
curl -s -o /dev/null -w "%{content_type} %{size_download}\n" \
  https://playzoo.snapaweb.com/crew/definitely-not-a-file.png
# -> text/html 2495    <- the control. This is what a MISS looks like, also with code 200.

# page actually changed (this was 0 before the timer ran):
curl -s https://playzoo.snapaweb.com/kickstarter | grep -c "rexsays"          # -> 7
curl -s https://playzoo.snapaweb.com/kickstarter | grep -o 'href="#[a-z]*">[0-9][0-9] [^<]*'
```

## 2. Ask John — what it is

John as PlayZoo's customer-support agent. Two surfaces, one gag: **Rex** tells visitors *"ask John —
fair warning, he'll try to sell you rubbish, don't buy it, and he loves being called a trash panda."*
Both halves are a stitch-up.

- **`apps/web/src/routes/AskJohnRoute.tsx`** at `/ask-john`. The app uses **hash routing**, so the
  real public URL is `playzoo.snapaweb.com/#/ask-john`. Deliberately public — Kickstarter visitors
  have no backer code yet, and gating it would break the funnel the campaign block creates.
- **`apps/server/john.js`** — `/api/john-chat` takes optional `mode`. `mode:"agent"` appends
  `JOHN_AGENT_RULES`: answer the real PlayZoo question **first**, then ~1 reply in 3 swerve into
  selling freshly invented worthless trash, priced in shiny acorns. The item is improvised every
  time, never a fixed list — a list repeats on regulars, and the unpredictability is the joke. He
  never takes money; it is a bit, not a transaction. The first trash-panda hit makes him accuse the
  visitor of being put up to it **by Rex**. Without the flag, waitlist John is unchanged.
- **Kickstarter block 05.** See §3 — the placement has a reason and is not to be reversed.

## 3. Block placement — 05, and why it stays there

It shipped at 11 (after the pledge CTA, to catch readers who scrolled past without backing). The
owner moved it to **05, straight after Meet Rex**, on 2026-09-08. The reasoning, on the record so a
later session does not "restore" the old position from the old rationale:

> Most visitors leave around halfway. A block that only converts readers who reach the END is one
> most of the traffic never sees, so late placement loses more than early placement. At 05 its job
> is to HOOK — John is funny, and funny buys the next scroll. It does not cost the pledge ask: a
> reader who does go the distance has already learned there is a live AI that answers questions,
> which is exactly what they want to know by the time they have questions.

The old rationale assumed scrolled-past-the-CTA readers exist in numbers. The drop-off says they
mostly do not. The same reasoning is in the block comment in `kickstarter/body.html`.

Renumbering touches three places that must stay in sync: the `.tab` labels, the top nav, and
`SECTIONS` in `kickstarter/export_ks.py`. The `NN-` filename prefix is what orders the upload on
Kickstarter, so a reorder RENAMES files — clear `dist/story/` first or stale PNGs survive.

## 5. Traps — found by LOOKING at output, invisible in the source

Both of the first two cost a round trip. Both will recur.

1. **`.beat img` forced `aspect-ratio:1/1` + `object-position:center bottom`.** Correct for block
   04's standing cut-out; wrong for a LANDSCAPE photo, which letterboxed into a dead band above the
   image that read as a half-loaded asset. The square frame is now scoped to `.cutout`. **Check any
   new `.beat` image for this.**

2. **`export_ks.py` failed reproducibly with `OSError Errno 22`** — and only on the block whose
   bytes had just changed. `dist/` lives inside a **OneDrive-synced** folder; OneDrive locks a file
   to upload it the moment it changes, so the next export cannot overwrite it. Unchanged files were
   never re-uploaded and never failed, which is what made it look random. Saves now go through
   `save_png()`: sibling temp file plus swap, with a retry. **Any script that rewrites files under
   this repo can hit this.**

3. **AI stage directions** (`24fc669`, earlier session) — `apps/server/speech.js` strips narration on
   the OUTPUT path, because the prompt rule was already there and DeepSeek ignored it. **Do not
   "simplify" it into deleting everything in asterisks:** that destroyed the joke (`I have a
   *business* degree` became `I have a degree`). Narration is removed; emphasis is unwrapped and the
   words kept. Verified still working post-deploy — "business degree" survives.
